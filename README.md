# JHERICON LLC — Five Page Website v6 (logo and clipping fixes)

Fixes:
- All five HTML pages contain an embedded optimized copy of the official JHERICON logo, so it displays even if the assets folder is missing on GitHub Pages.
- Improved header/footer logo contrast and responsive text layouts.

## Deploy
Upload/replace **all five HTML pages and styles.css** in the root of the existing GitHub repository. Keep script.js. The included assets folder is optional for the embedded logo but retained as the master image. Commit to the same branch used by GitHub Pages. Then hard refresh Ctrl+Shift+R.

Pages: index.html, about.html, services.html, training.html, contact.html.
