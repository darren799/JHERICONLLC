# JHERICON LLC — Five-Page GitHub Pages Website (v3)

Upload **the contents of this folder** to the ROOT of your existing `darren799/JHERICONLLC` repository. Do not upload the containing directory or the ZIP itself. Replace the existing `index.html`, `styles.css`, and `script.js`. Add the four new HTML files and keep the `assets` folder.

## The five pages
- `index.html` — Home
- `about.html` — About / vision / community impact
- `services.html` — Consulting, AI, government solutions, draft NAICS areas
- `training.html` — Proposed courses / training inquiry
- `contact.html` — Contact / general inquiry

`styles.css`, `script.js`, and `assets/jhericon-logo.png` are shared. Links are relative, so the site works on GitHub Pages at `/JHERICONLLC/`.

## Configure contacts
Edit `script.js` under `SITE_CONFIG` and enter the verified business email and phone. The forms generate email drafts using `mailto:`. They DO NOT transmit to a database or complete enrollment. Use a secure form backend when you are ready for live registrations.

## Verify before publishing claims
The company capability statement is a draft. Veteran business certification, contracting eligibility, UEI/CAGE, and exact registered NAICS codes need verification. The site does not present those claims as certified. JHERICON currently operates as an LLC and is not represented as tax-exempt.
